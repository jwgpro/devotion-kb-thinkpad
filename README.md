# Devotion keyboard: ThinkPad

STM32-based USB controller boards intended for old ThinkPad keyboards with the same 40-pin connector; T60, T420, etc.

`kb-only`: Simple board connecting all pins of a 40-pin keyboard connector (0.5 mm pitch) to STM32 I/O pins. No trackpoint supported. Could be used for any keyboard conforming to the same FFC/FPC connector.

`full`: **(TODO)** With trackpoint support. For specific keyboards only.

Other variants planned.
